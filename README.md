# 🌕 Lunar Landing Site Navigator 

**NASA Space Apps Challenge 2026 Submission**

## 🚀 Overview
The Lunar Landing Site Navigator is a Next.js-based web application designed to evaluate and visualize optimal landing zones on the Moon. By processing critical environmental constraints—such as `timeToEarthsetHours`, slope, and power potential—the platform assists in identifying the safest and most efficient locations for lunar modules.

## ✨ Key Features
- **Constraint-Gating Logic:** Dynamically filters landing sites based on strict safety and operational parameters.
- **Interactive UI:** Built with React and Next.js for a seamless, responsive mission-control experience.
- **Real-Time Evaluation:** Processes lunar telemetry data to output immediate landing viability scores.

## 💻 Tech Stack
- **Framework:** Next.js (React)
- **Language:** TypeScript
- **Styling:** Tailwind CSS / CSS Modules
- **Deployment:** Vercel
